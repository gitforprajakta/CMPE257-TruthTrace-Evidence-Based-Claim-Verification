Can a semantic model beat TF-IDF on the same claims?

TruthTrace compares two claim-verification models on AVeriTeC: one traditional, one semantic. Both see the same claims, the same evidence, and the same four verdicts.

Can a semantic model (Sentence-BERT + logistic regression) beat a traditional model (TF-IDF + logistic regression) for claim verification, given identical data, splits, tuning budget, and metrics?

What the comparison says

The majority baseline reaches a macro-F1 of 0.1926. TF-IDF + logistic regression reaches a macro-F1 of 0.4693. Sentence-BERT + logistic regression reaches a macro-F1 of 0.3596. The macro-F1 difference (SBERT minus TF-IDF) is -0.1095 with a 95% bootstrap interval of [-0.1796, -0.0392]. McNemar's test on paired correctness gives p = 1.38e-07. SBERT is worse than TF-IDF at alpha = 0.05.

Decision support only. A verdict is a model's reading of this benchmark. It is not a determination that a claim is true or false in the world.
